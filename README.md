# 📊 Sales & Customer Dashboard

This project provides interactive **Sales** and **Customer** dashboards designed to analyze business performance, track trends, and derive insights. The dashboards are built with data analytics tools and offer flexibility for dynamic analysis and year-over-year comparisons.

---

## 📈 Sales Dashboard | Requirements

### 🎯 Dashboard Purpose
The purpose of the **Sales Dashboard** is to present an overview of key sales metrics and trends to:

- Analyze **year-over-year sales performance**
- Understand **monthly, weekly, and categorical sales behaviors**

### ✅ Key Requirements

#### 🔹 **KPI Overview**
- Display total **Sales**, **Profits**, and **Quantity** for:
  - **Current Year**
  - **Previous Year**

#### 🔹 **Sales Trends**
- Show **monthly trends** for each KPI for both years
- Highlight:
  - Month with **Highest Sales**
  - Month with **Lowest Sales**

#### 🔹 **Product Subcategory Comparison**
- Compare **sales performance** by **Product Subcategory**:
  - For the **current and previous year**
  - Include comparison of **Sales** vs **Profit**

#### 🔹 **Weekly Trends for Sales & Profit**
- Present **weekly Sales and Profit data** for the current year
- Display **average weekly values**
- Highlight weeks that are:
  - **Above Average**
  - **Below Average**

---

## 👥 Customer Dashboard | Requirements

### 🎯 Dashboard Purpose
The **Customer Dashboard** provides insights into customer data, trends, and behaviors. It helps:

- Understand **customer segments**
- Improve **marketing strategies**
- Enhance **customer satisfaction**

### ✅ Key Requirements

#### 🔹 **KPI Overview**
- Display total:
  - **Number of Customers**
  - **Sales per Customer**
  - **Number of Orders**
- For the **current and previous year**

#### 🔹 **Customer Trends**
- Monthly breakdown of each KPI for both years
- Highlight:
  - Month with **Highest Sales**
  - Month with **Lowest Sales**

#### 🔹 **Customer Distribution by Number of Orders**
- Visualize customer distribution based on **number of orders placed**
- Gain insights into:
  - **Customer loyalty**
  - **Engagement levels**

#### 🔹 **Top 10 Customers by Profit**
- Present:
  - **Top 10 most profitable customers**
  - Additional details:
    - **Rank**
    - **Number of Orders**
    - **Current Sales**
    - **Current Profit**
    - **Last Order Date**

---

## 🧩 Design & Interactivity Requirements

### 📅 Dashboard Dynamics
- Allow users to **select any desired year** to view historical data
- Enable **easy navigation** between dashboards
- Make **charts and graphs interactive** to allow filtering via charts

### 🎛️ Data Filters
- Allow filtering by:
  - **Product Information**: Category, Subcategory
  - **Location Information**: Region, State, City
