# 🧑‍💼 HR Dashboard

This project provides a comprehensive **HR Dashboard** for analyzing human resources data. It offers both **summary views** for high-level insights and a detailed **employee records view** for in-depth analysis. Designed to support HR managers in strategic decision-making and workforce analytics.

---

## 📌 User Story

**As an HR manager**, I want a comprehensive dashboard to analyze human resources data, providing:

- Summary views for high-level insights
- Detailed employee records for in-depth analysis

---

## 🧾 Summary View

The **Summary View** is divided into three main sections:

### 📊 1. Overview

Provides a snapshot of overall HR metrics:

- Display the **total number of hired**, **active**, and **terminated employees**
- Visualize **year-over-year trends** for hiring and termination
- Show a **breakdown of employees** by:
  - Department
  - Job Titles
- Compare employee counts between:
  - **Headquarters (New York)** and
  - **Branches**
- Show **geographic distribution** of employees by:
  - **City**
  - **State**

---

### 👥 2. Demographics

Offers insights into workforce composition:

- Present the **gender ratio**
- Visualize the distribution across:
  - **Age groups**
  - **Education levels**
- Show total employees by:
  - **Age group**
  - **Education level**
- Present **correlation between education levels and performance ratings**

---

### 💰 3. Income Analysis

Focuses on salary-related metrics:

- Compare **salaries across education levels and gender** to identify discrepancies or patterns
- Present how **age correlates with salary** across departments

---

## 📋 Employee Records View

A detailed, filterable view of all employee data.

- Display comprehensive records with:
  - **Name**
  - **Department**
  - **Position**
  - **Gender**
  - **Age**
  - **Education**
  - **Salary**
- Enable **column-based filtering** for all available attributes

---

## 🎯 Purpose

This dashboard aims to empower HR managers with:

- Data-driven workforce analysis
- Strategic insights into employee trends
- Support for diversity, equity, and inclusion evaluations
- Salary fairness and performance assessment

---

## 🧩 Features at a Glance

- High-level KPIs and breakdowns
- Interactive charts and filters
- Detailed tabular data with search and sort
